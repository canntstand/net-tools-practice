# net-linux-setup

Проект по настройке сетевого шлюза на базе Linux (Ubuntu 22.04+).

## Компоненты
- **Netplan**: Управляет сетевыми интерфейсами.
- **nftables**: Обеспечивает фильтрацию трафика и NAT (Masquerade).

## Требования
- Два сетевых интерфейса: `enp1s0` (Интернет) и `enp2s0` (LAN).

## Установка
1. Клонируйте репозиторий.
2. Проверьте имена своих интерфейсов через `ip link` и при необходимости подправьте конфиги в папках `netplan/` и `nftables/`.
3. Запустите скрипт установки:
   ```bash
   chmod +x setup.sh
   ./setup.sh
   ```

## Проверка
- Статус сети: `networkctl status`
- Статус брандмауэра: `sudo nft list ruleset`
